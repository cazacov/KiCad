# KiCad
My KiCad projects

## Setup
Environment variables:
- KICADLIB_SKISELEV - Path to Sergey Kiselev's KiCad library
- KICADLIB_VICTOR - Path to my KiCad library

### Symbol Libraries
- ${KICADLIB_SKISELEV}/library/my_components.kicad_sym
- ${KICADLIB_VICTOR}/symbols/VictorLib.kicad_sym

### Footprint Libraries
- ${KICADLIB_SKISELEV}/My_Components.pretty
- ${KICADLIB_VICTOR}/footprints/VictorLib.pretty
